# Instagram amber（タイ古式マッサージサロン）運用 — 作業の前提

このディレクトリは、タイ古式マッサージサロン「amber」の Instagram 運用を管理する。
共通の作業手順・テンプレート・技術仕様はリポジトリ直下の `CLAUDE.md` と `docs/reels-creation-procedure.md` に従う（アカウントを問わず共通）。**ルート `CLAUDE.md` の「アカウントの前提」「分かっていること（実測）」「生肉を扱う企画での必須記載」はレシピアカウント専用の内容なので、amber の作業では参照しない。**

## 投稿カテゴリ

| カテゴリ | 内容 | 台本ファイルの接頭辞 |
| --- | --- | --- |
| おすすめメニュー | サロンの施術メニュー紹介 | `menu_` |
| 健康セルフチェック | 視聴者が自分でできる不調チェック | `selfcheck_` |
| お客様の声 | 利用者インタビュー・感想 | `voice_` |
| スタッフ募集 | 求人・採用訴求 | `recruit_` |

台本は `docs/scripts/` に `<接頭辞>YYYYMM_企画名.md` で置く。分析は `docs/analysis/` に `<接頭辞>YYYY-MM-DD_企画名.md` で置く。

## カテゴリ別の注意点

投稿前チェックリスト（`docs/templates/pre-post-checklist.md`）の「6. 法務・ガイドライン」は共通で必ず確認する。加えて、以下はこのアカウント特有の注意点。

- **健康セルフチェック**：あくまで一般的なセルフチェック情報として扱い、診断・治療を断定する表現（「〇〇病です」「これで治る」等）は使わない。医療的な助言に見える表現になっていないか、投稿前に承認者が確認する。
- **お客様の声**：出演者（お客様）本人から、動画・写真の利用と公開範囲について明確な許諾を得てから撮影・投稿する。未成年が映る場合は保護者の許諾も必要。
- **スタッフ募集**：求人の実態がある内容（給与・勤務地・勤務時間など）を含む場合、実際の求人条件と食い違いがないか確認する。年齢・性別等を理由に応募者を限定するような表現は避ける。

## 素材フォルダの構成

ルート `CLAUDE.md` の規約に、アカウント名の接頭辞を付けて運用する（ローカルのみ・git 管理外）。

```
素材/amber_YYYYMMDD_企画名/
  ├── 01_素材/      撮影した元データ（無加工・触らない）
  ├── 02_書き出し/  作業中・完成データ
  └── 03_テロップ/  合成用のPNG
```

## やらないこと

- ルート `CLAUDE.md` の「やらないこと」をそのまま適用する（動画ファイルは git にコミットしない、元素材を上書きしない等）
