# Instagram リール作成 手順書

| 項目 | 内容 |
| --- | --- |
| 文書名 | Instagram リール作成 手順書 |
| バージョン | 1.0 |
| 適用範囲 | 自社 Instagram アカウントで公開するリール（Reels）の企画・撮影・編集・投稿・振り返りまで |
| 対象者 | SNS 運用担当者、撮影・編集担当者、確認・承認者 |
| 関連文書 | [企画シート](templates/reel-planning-sheet.md) / [投稿前チェックリスト](templates/pre-post-checklist.md) |

> **注意:** Instagram の仕様（最大尺・画面サイズ・機能名）は頻繁に変更されます。本書の数値は目安として扱い、実作業前に必ず [Instagram ヘルプセンター](https://help.instagram.com/) の最新情報を確認してください。

---

## 1. 目的

本書は、リール制作の品質と速度を担当者に依存させずに一定に保つことを目的とし、以下を定める。

- 企画から投稿までの標準的な作業ステップと担当
- 各ステップの完了条件（次に進んでよい状態）
- 投稿前に必ず確認する項目
- 投稿後の効果測定と改善の進め方

## 2. 全体フロー

```
[1] 企画       →  [2] 構成作成  →  [3] 撮影      →  [4] 編集
 企画シート作成     台本・カット表    素材撮影         カット/テロップ/音源
      ↓                 ↓              ↓                  ↓
   企画承認          構成確認       素材チェック        初稿完成
                                                          ↓
[7] 振り返り  ←  [6] 投稿      ←  [5] 確認・承認
 数値分析          公開・固定       修正指示 → 反映 → 承認
```

標準リードタイムの目安（1 本あたり）

| ステップ | 担当 | 所要時間の目安 | 完了条件 |
| --- | --- | --- | --- |
| 1. 企画 | 運用担当 | 30 分 | 企画シートが埋まり、承認者が OK |
| 2. 構成作成 | 運用担当 | 30 分 | 冒頭 3 秒とカット割りが確定 |
| 3. 撮影 | 撮影担当 | 60 分 | 必要カットが全部撮れて、確認済み |
| 4. 編集 | 編集担当 | 90 分 | 尺・テロップ・音源が入った初稿 |
| 5. 確認・承認 | 承認者 | 30 分 | チェックリスト全項目 OK |
| 6. 投稿 | 運用担当 | 15 分 | 公開完了、投稿記録に追記 |
| 7. 振り返り | 運用担当 | 15 分 | 投稿 7 日後に数値を記録 |

## 3. 事前準備（初回のみ / 変更時）

### 3.1 アカウント設定

1. アカウントを**プロアカウント**（ビジネスまたはクリエイター）に切り替える。
   - プロフィール → 三本線メニュー → 設定とプライバシー → アカウントの種類とツール → プロアカウントに切り替える
   - ※インサイト（分析データ）はプロアカウントでのみ利用できる。
2. 「設定とプライバシー → アカウントの種類とツール → 元の音源」でオリジナル音源の利用可否を確認する。
3. 画質設定を確認する。
   - 設定とプライバシー → メディアの画質 → **「最高画質でアップロード」を ON**
   - OFF のままだとアップロード時に大きく圧縮される。

### 3.2 機材・ツール

| 種別 | 標準 | 備考 |
| --- | --- | --- |
| 撮影 | スマートフォン（背面カメラ） | 前面カメラは画質が落ちるため原則使用しない |
| 固定 | 三脚 / スマホホルダー | 手ブレは離脱の主要因 |
| 照明 | リングライト or 自然光 | 逆光を避け、被写体の正面から当てる |
| 音声 | 外部マイク（ピンマイク） | 声を入れる企画では必須 |
| 編集 | 指定の編集アプリ | アプリ名・ライセンスは運用ルールに従う |
| 保管 | 共有ストレージ | 撮影素材・書き出しデータの保存先 |

### 3.3 素材の保管ルール

```
/リール/YYYY/MM/YYYYMMDD_企画名/
    ├── 01_素材/      撮影した元データ（無加工）
    ├── 02_編集/      編集プロジェクトファイル
    ├── 03_書き出し/  投稿用の完成データ
    └── 企画シート.md
```

- ファイル名は `YYYYMMDD_企画名_連番` で統一する。
- 元素材は最低 3 か月保管し、勝手に削除しない。

## 4. ステップ 1：企画

### 4.1 手順

1. [企画シート](templates/reel-planning-sheet.md)を複製する。
2. 次の 5 項目を埋める。
   - **ターゲット**：誰に向けるか（1 人に絞る）
   - **目的**：認知 / 保存 / 送客 / 販売 のいずれか 1 つ
   - **視聴者の得**：見た人が何を得るか（1 文で）
   - **テーマ**：具体的な題材
   - **CTA**：最後に何をしてほしいか（保存・フォロー・プロフィールへ）
3. 承認者に企画シートを共有し、承認を得る。

### 4.2 企画の型（迷ったらここから選ぶ）

| 型 | 内容 | 向いている目的 |
| --- | --- | --- |
| ハウツー | 手順を分解して見せる | 保存 |
| ビフォーアフター | 変化を最初と最後で見せる | 認知・保存 |
| よくある失敗 | NG 例 → 正解の順で見せる | 保存 |
| 比較 | A と B を並べる | 認知 |
| 裏側 | 制作・準備の様子 | ファン化 |
| Q&A | 実際に来た質問に答える | 信頼獲得 |

### 4.3 完了条件

- [ ] 企画シートの必須項目がすべて埋まっている
- [ ] 目的が 1 つに絞られている
- [ ] 承認者の承認が取れている

## 5. ステップ 2：構成作成

### 5.1 尺の設計

| 区間 | 時間の目安 | 役割 |
| --- | --- | --- |
| フック | 0〜3 秒 | 「自分に関係がある」と思わせる |
| 本編 | 3〜25 秒 | 結論 → 理由 → 具体例 |
| CTA | 最後の 3 秒 | 次の行動を 1 つだけ提示 |

- 全体の標準尺は **15〜30 秒**。長い解説企画でも 60 秒以内を目安とする。
- 1 カットは 2〜3 秒を上限とし、画に変化を作る。

### 5.2 冒頭 3 秒の作り方

視聴維持率は冒頭でほぼ決まる。次のいずれかを必ず入れる。

- 結論を先に言う（例：「これ、やらない方がいいです」）
- 対象を名指しする（例：「〇〇で困っている人へ」）
- 数字を出す（例：「3 つだけ覚えてください」）
- 意外な画・音から始める

**避けること**：挨拶・自己紹介から始める、前置きが長い、ロゴアニメーションを先頭に置く。

### 5.3 カット表の作成

企画シートのカット表に、カットごとに以下を書く。

| No | 秒数 | 映像（何を撮るか） | セリフ / テロップ | 備考 |
| --- | --- | --- | --- | --- |
| 1 | 0-3 | 手元アップ | 「これ、間違ってます」 | フック |
| 2 | 3-8 | 引きの画 | 理由を説明 | |

### 5.4 完了条件

- [ ] 冒頭 3 秒の内容が具体的に決まっている
- [ ] 全カットの秒数合計が目標尺に収まっている
- [ ] CTA が 1 つに絞られている

## 6. ステップ 3：撮影

### 6.1 撮影前の確認

- [ ] レンズを拭いた
- [ ] 端末の空き容量が十分（目安 5GB 以上）
- [ ] バッテリー残量 50% 以上
- [ ] 撮影解像度 1080p 以上 / 30fps 以上に設定
- [ ] **縦向き（9:16）**で構える
- [ ] 通知をオフ（撮影中の着信・通知音を防ぐ）

### 6.2 撮影のルール

1. **縦位置で撮る。** 横で撮った素材は上下に余白ができ、使えない。
2. **安全マージンを空ける。** 画面の上下端はテロップや UI（いいねボタン、キャプション）と重なるため、被写体や重要な文字を置かない。
   - 上端：約 15%、下端：約 20% を空ける
3. **同じカットを 3 テイク撮る。** 編集で選べるようにする。
4. **各カットの前後に 1 秒余分に回す。** カット編集のノリシロにする。
5. **音を録る企画では、静かな環境で撮る。** エアコン・換気扇は止める。
6. **明るさは撮影で作る。** 編集で明るくすると画質が荒れる。

### 6.3 撮影直後の確認

- [ ] ピントが合っている
- [ ] 手ブレがない
- [ ] 音が割れていない・小さすぎない
- [ ] 映ってはいけないもの（個人情報、他人の顔、他社ロゴ、社外秘資料）が入っていない
- [ ] カット表の必要カットがすべて揃っている

**この場で確認する。** 撮り直しは現場でしかできない。

### 6.4 完了条件

- [ ] 必要カットが全て揃い、上記確認が済んでいる
- [ ] 素材を保管ルールどおりに保存した

## 7. ステップ 4：編集

### 7.1 書き出し仕様

| 項目 | 指定値 |
| --- | --- |
| アスペクト比 | 9:16（縦） |
| 解像度 | 1080 × 1920 px |
| フレームレート | 30fps（元素材に合わせる） |
| 形式 | MP4（H.264） |
| 音声 | AAC、ステレオ |

### 7.2 編集手順

1. **カット編集**：カット表の順に並べ、間・言い淀みを削る。テンポ優先。
2. **テロップ**：
   - 音を出さずに見る視聴者が多いため、**話す内容は必ず文字にする**。
   - フォントサイズは、スマホ画面で読める大きさ（画面幅の 1/12 以上を目安）。
   - 文字色は背景とコントラストを付ける（白文字＋黒フチが無難）。
   - 上下の安全マージン内に文字を置かない。
3. **音源**：
   - Instagram アプリ内の音源ライブラリから選ぶことを原則とする。
   - 外部音源を使う場合は、商用利用可能なライセンスを取得済みのものだけを使う（[9. 法務・ガイドライン](#9-法務コミュニティガイドライン) 参照）。
   - 声がある企画では BGM を下げ、声を主役にする。
4. **仕上げ**：
   - 冒頭 3 秒に無駄がないか見直す。
   - スマホの実機で、音を出さずに 1 回、音を出して 1 回、通しで確認する。

### 7.3 やってはいけないこと

- 他プラットフォームの**ロゴ入り透かし**が入った素材を使う（表示が伸びにくい）
- 画質が荒い素材の引き伸ばし
- テロップが画面外にはみ出す
- 音量が他の投稿と大きく違う

### 7.4 完了条件

- [ ] 指定仕様で書き出せている
- [ ] 実機確認（無音・有音の 2 回）が済んでいる
- [ ] 書き出しデータを保管ルールどおりに保存した

## 8. ステップ 5：確認・承認

1. 編集担当が、書き出しデータと投稿文案（キャプション・ハッシュタグ・カバー画像）を承認者に提出する。
2. 承認者は[投稿前チェックリスト](templates/pre-post-checklist.md)の全項目を確認する。
3. 修正がある場合は、指摘を**まとめて 1 回で**返す。編集担当が反映し、再提出する。
4. 承認者の承認をもって投稿可とする。

**承認なしの投稿は禁止。**

---

## 9. ステップ 6：投稿

### 9.1 投稿手順

1. Instagram アプリで「＋」→「リール」を選択し、書き出した動画を選ぶ。
2. **カバー画像**を設定する。
   - 動画中のフレーム、または別途用意した画像をアップロードする。
   - カバーにも短い文字（企画タイトル）を入れると、プロフィール上で内容が分かる。
   - プロフィールのグリッド表示で中央が切れるため、**中央に主要素**を置く。
3. **キャプション**を入力する。
   - 1 行目に、動画の内容が分かる一言（一覧で最初に見える箇所）。
   - 続けて補足説明、最後に CTA。
   - 目安 100〜300 文字。長い場合は改行で読みやすくする。
4. **ハッシュタグ**を入力する。
   - 3〜5 個程度。内容と関係のないタグは付けない。
   - 構成の目安：大（10 万件以上）1 個、中（1 万〜10 万件）2 個、小（1 万件未満）2 個
5. **その他の設定**を確認する。
   - 場所（該当する場合）
   - タグ付け（共演者・協力先の許可を得ている場合のみ）
   - Facebook への同時投稿（運用ルールに従う）
   - コメントの許可設定
6. 「シェア」を押して公開する。

### 9.2 投稿後すぐにやること

- [ ] 公開された投稿を自分で開き、再生・表示崩れがないか確認する
- [ ] キャプションの誤字を確認する（公開後も編集可能）
- [ ] 投稿記録（スプレッドシート等）に、日時・企画名・URL を追記する
- [ ] 最初の 1 時間はコメントを確認し、返信する

### 9.3 投稿タイミング

- インサイトの「オーディエンス → 最もアクティブな時間帯」を確認し、その 30〜60 分前に投稿する。
- 目安の投稿頻度は**週 3〜5 本**。まず頻度を安定させる。

## 10. ステップ 7：振り返り

### 10.1 確認する指標

投稿から 24 時間後・7 日後に、インサイト（リール → インサイトを表示）で以下を記録する。

| 指標 | 見るポイント | 悪いときの主な原因 |
| --- | --- | --- |
| 再生数 | 全体のリーチ | 企画の需要、フック |
| 視聴維持率 / 平均視聴時間 | どこで離脱したか | 冒頭 3 秒、テンポ |
| 保存数 | 「後で見返す価値」があったか | 情報の具体性 |
| シェア数 | 人に見せたくなったか | 共感・驚き |
| いいね・コメント | 反応の量 | 問いかけの有無 |
| プロフィールアクセス | 送客できたか | CTA の弱さ |
| フォロー数 | 新規獲得 | プロフィールの整備不足 |

**最重要は視聴維持率と保存数。** 再生数だけを追わない。

### 10.2 改善の進め方

1. 冒頭 3 秒での離脱が大きい → フックを作り直す（結論を先に、テロップを大きく）
2. 中盤で離脱する → カットを詰める、1 本の情報量を減らす
3. 最後まで見られるが保存されない → 「持ち帰れる情報」を足す
4. 保存はされるがフォローされない → CTA とプロフィール文を見直す

- 月 1 回、上位 3 本と下位 3 本を並べて共通点を洗い出し、企画の型を更新する。
- 伸びた投稿は、切り口を変えて作り直す（同じ内容の再投稿はしない）。

## 11. 法務・コミュニティガイドライン

投稿前に必ず確認する。

- **著作権**：音楽・映像・画像・フォントは、権利が確認できたものだけ使う。テレビ番組、他人の投稿、Web 上で拾った画像の無断使用は禁止。
- **音源**：ビジネスアカウントでは利用できる音源が制限される場合がある。使用前にアプリ上で利用可否を確認する。
- **肖像権**：人物が映る場合は、本人（未成年は保護者）の許可を得る。第三者が映り込んだ場合はぼかす。
- **広告表示**：企業から対価を受けた投稿には、「タイアップ投稿ラベル」を付け、本文にも #PR 等を明記する。景品表示法・ステマ規制に従う。
- **薬機法・景表法**：効果効能をうたう表現（「治る」「必ず痩せる」等）を使わない。
- **機密情報**：社内資料、顧客情報、未発表情報の映り込みを確認する。
- **コミュニティガイドライン**：Instagram の規約に反する内容（誤情報、危険行為、権利侵害）は投稿しない。

判断に迷う場合は投稿を止め、承認者または法務担当に確認する。

## 12. トラブルシューティング

| 症状 | 確認すること | 対処 |
| --- | --- | --- |
| 画質が荒い | 「最高画質でアップロード」設定、書き出し解像度 | 設定を ON にし、1080×1920 で書き出し直す |
| アップロードが途中で止まる | 通信環境、アプリのバージョン、端末の空き容量 | Wi-Fi に接続、アプリを最新版に更新、再起動 |
| 音源が選べない | アカウント種別（ビジネスは制限あり）、権利状況 | 別の音源に差し替える、オリジナル音源を使う |
| テロップが UI で隠れる | 上下の安全マージン | 上 15% / 下 20% の外に文字を出さない |
| 全く再生数が伸びない | 透かし入り素材、ガイドライン抵触、投稿直後 | 素材を作り直す。24 時間は様子を見る |
| 投稿後に誤字を発見 | — | キャプションは編集可能。動画自体は差し替え不可のため、削除して再投稿するか判断する（再投稿は数値がリセットされる） |
| 動画が投稿できない | 尺、形式、ファイルサイズ | 仕様どおり（9:16 / MP4 / H.264）に書き出し直す |
