## 効いている要素

1. **数字バッジ「protein 40g」** — 全投稿に統一で入っている。1本の工夫ではなくアカウント全体の型
2. **0秒が動作の超ドアップ** — 引きの画にしない。0フレーム目からもう削っている
3. **最初のテロップが6モーラ** — 「これ知ってる？」だけ。1.6秒で切替。最初の1.2秒は声なし
4. **予告編 → 本編の2周構造** — 離脱を前提にした設計
5. **テロップが1.2秒ごと** — 25.9秒で21回。長い文が1つもない
6. **文を最後までまたがせる** — 「フワフワ食感」→「ぜったい思うよ」→「って」→「またつくろー」
7. **顔出しの実食と商品ラベル** — 再現できそう・本当に食べていると伝わる
8. **絵文字1つで答えられるコメント誘導** — 「【🥒】をコメントで」。コメント86件はこれで取っている
9. **キャプション約1,000字** — 1行目に実績、手順に「なぜ」、安全記載、メンション、季節タグ（#夏バテ）

## ラストのフォロー誘導について

参考元もプロフィールのグリッドで終わっている（2.1秒 / 尺の8%）。
ただし**グリッドに protein バッジが15枚並んでいる絵**になっていて、
「フォローすると何が手に入るか」が映像で伝わる。コピーも「食べたいけど太りたくない人🙌」。

8/27のふじさんの投稿は3.0秒（尺の14%）で、フォローボタンに赤丸を付けただけだった。
**削るべきなのは「フォロー誘導」ではなく「理由が映っていないフォロー誘導」。**
バッジができてグリッドに並んだら復活させる。

## 取るもの / 取らないもの

**型として取る**

- 予告編 → 本編の2周構造
- 0秒＝動作の超ドアップ
- 最初のテロップを1フレーズ・1.6秒以内に
- テロップを1.2秒ごとに切り替える
- 文を最後までまたがせる
- 数字バッジを全投稿に統一で載せる（型は取り、数字の中身は変える）
- 調味料のラベルを映す／実食カットを入れる
- キャプション1行目に、指示ではなく情報を置く
- コメント誘導を絵文字1つで答えられる形にする
- 手順に「なぜ」を1つ添える／道具と調味料をメンションする
- 安全上の注意を厚く書く（この企画では必須）

**取らない**

- 「protein 40g」そのもの（相手の識別子。同じ軸に乗ると後発の劣化版に見える）
- テロップの文言・ナレーションの言い回し・料理名の付け方
- 同じ味付け（ポン酢＋梅＋きゅうり）。技も食材も冷凍も同じなので、味付けまで揃うと模倣
- 【🥒】という絵文字の選び方（型は取り、絵文字は自分の料理のものにする）
- 縦書きタイトルのレイアウトをそのまま真似ること

## 数字バッジの案

冷凍が差別化にならない以上、違いは「何を約束するアカウントか」に置く。
参考元の約束は**タンパク質の量**、ふじさんの約束は**時間**。

| 案 | 評価 |
| --- | --- |
| **解凍 0分** | **推奨。** 軸がぶつからず、ピーラー企画と直結する |
| 10min | 素直だが時短系は競合が多く埋もれる |
| 包丁 0 | 今回とは相性が良いが、毎回は成立しない |

バッジは全投稿に同じ位置・同じ書式で入れて初めて効く。1本だけでは意味がない。
