# Metaアルゴリズムの動向と台本への反映（2026年9月時点）

> **出典の信頼度について：** about.instagram.com（Instagram公式ブログ）へは今回ネットワーク制限で直接アクセスできなかった。以下はAdam Mosseri（Instagramトップ）の発言を引用しているマーケティング系メディア・SEOブログ複数（dataslayer.ai / eclincher.com / Hootsuite / socialpilot.co ほか）の記述をもとにしている。**方向性は複数ソースで一致しており信頼して良いが、「いいねの3〜5倍」のような具体的な倍率は各メディアの推定・意訳であり、Meta公式の一次数値ではない。** 数値そのものではなく、優先順位の向きとして読むこと。次回このリポジトリの「Meta変更チェック」（毎朝Routine）で一次情報が取れたら、この文書を更新する。

## 分かっていること

1. **視聴時間・完了率・リプレイ回数が最重要シグナル。**
   Mosseriが2026年1月に「15秒のリールを3回見る」ほうが「60秒のリールを1回見る」より評価が高いと明言（と複数メディアが報道）。**尺を伸ばすより、もう一度見たくなる作りのほうが有利**、という向き。
2. **シェア（特にDMで友達に送る）が、いいねより重い。**
   Mosseri自身は具体的な倍率を明言していないが、「送信は最も強いランキングシグナルの一つ」という趣旨の発言を継続して行っている。いいねは「見た」の記録に近く、送信は「人に勧めた」という強い意思表示として扱われている。
3. **オリジナリティ判定が強化された（2026/4/30の変更と報道）。**
   同じ動画の使い回し・他アカウントの構成をそのまま流用する投稿は、レコメンド面から除外されやすくなった。写真・カルーセルも同様の基準に統一。
4. **「Your Algorithm」機能がFeed/Reels/Explore全面に展開（2026/6/10）。**
   ユーザーが「もっと見る／見たくない」を直接操作できるようになった。同じジャンル・同じキーワードを一貫して使うアカウントほど「このジャンルが好きな人」に登録されやすくなる方向。
5. **キャプションのキーワードが、ハッシュタグより重視される方向。**
   検索・興味ベースのレコメンドにシフトしており、ハッシュタグを大量に付けるより、キャプション本文に検索されそうな言葉（料理名・食材名・「時短」「冷凍ストック」など）を自然文で入れるほうが効くとされる。
6. **Mosseriの年末メモ：「作り込みすぎた見た目」より「生々しさ・リアルさ」を2026年は評価する。**
   AI生成っぽい・広告っぽい過度な作り込みより、実際に手を動かしている手持ち感のある映像を優先する方向性。

## 次回台本への具体的な申し送り

- CTAは引き続き動画内では「保存」1つ。**キャプション末尾に「送る」を促す一文を追加する案をA/Bで試す**（例：umegoma-torishabuの次の投稿から）
- キャプション1〜2行目に、ハッシュタグに頼らず検索されそうな言葉（料理名＋「時短」「冷凍ストック」）を自然文で入れる
- ループ設計（0秒と最終カットの接続）は今後も全投稿で標準にする。可能なら「もう一度見たくなる」仕掛け（分量の再掲を一瞬だけ、など）を加える
- 同一素材・同一カット割りの使い回しはしない（オリジナリティ判定の強化）
