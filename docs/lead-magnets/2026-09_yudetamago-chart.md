# 配布特典「ゆで卵（蒸し卵）早見表」

## 目的・配布方法

- コメント誘導→DM配布の特典として使う（コメント数増加＋保存誘発の狙い）
- 形式：縦長PNG1枚（DMでそのまま画像添付できる想定）
- 手動DM対応。フォロワー規模的に自動化ツールは現時点では不要

## 前提にする調理法

ユーザー確定済みの条件：

| 項目 | 内容 |
| --- | --- |
| 鍋の水量 | 底から約1cm |
| 卵の温度 | 冷蔵庫から出してすぐ（常温に戻さない） |
| 投入タイミング | 水と卵を最初から一緒に火にかける（沸騰後投入ではない） |
| 蓋のタイミング | 最初は蓋なしで加熱し、**沸騰を確認してから蓋をする**（加熱時間の起点を目視で分かるようにするため） |
| 時間の数え方 | 火を止めたあとの余熱時間も含める |

## データの状態：仮（要実測）

参考にした情報源は「沸騰させてから卵を投入する」方式の数値。今回の方式は水と卵を**最初から一緒に**加熱するため、沸騰に達するまでの時間が余分にかかり、同じ半熟でも合計時間は参考値よりやや長くなるはず。鍋のサイズ・卵の個数・火力でも変動するため、**下表は仮データ**として置き、実測後に差し替える。

参考値（沸騰後に卵投入する方式）：蓋をして4分加熱 → 消火後、半熟は余熱3〜5分、固茹では余熱10分以上
出典：[水は1cmでOK！フライパンで作る半熟ゆで卵 - macaroni](https://macaro-ni.jp/103315) / [ゆで卵の作り方｜水1cmだけ - 富士山の裾野で何かをつぶやく](https://blog.cool-rock.com/easy-boiled-egg-1cm-water/)

### 仮表（沸騰後を起点とする）

| 仕上がり | 蓋をして加熱 | 消火後の余熱 |
| --- | --- | --- |
| とろとろ半熟 | 4分 | 2分 |
| 半熟（とろ〜り） | 4分 | 4分 |
| 半熟固め（味玉向き） | 4分 | 6分 |
| 固茹で目前 | 4分 | 9分 |
| しっかり固茹で | 4分 | 12分以上 |

## 実測でやること（次のステップ）

1. 卵2〜3個・水1cmで火にかけ、**沸騰するまでの時間**を計測（現状未確定）
2. 沸騰確認後、蓋をして火を止めるタイミングを複数パターン試す
3. 各パターンで余熱を2分刻みに区切り、卵を割って断面を撮影→黄身の固まり具合を記録
4. 実測値で上表を差し替え、このファイルを更新してコミット

## 配布物

- ドラフトPNG（仮データ版・実測前のためウォーターマーク入り）をユーザーに送付済み
- 断面図は実写素材が用意できなかったため、色とグラデーションで半熟〜固茹でを描き分けたイラストで代替（この作業環境は一般Webサイトへの通信がネットワークポリシーでブロックされており、ストックフォトサイトからのダウンロードができなかったため）
- 実測完了後、ウォーターマークなしの配布用最終版を作成する。写真素材が用意できる場合はイラストと差し替え可能
