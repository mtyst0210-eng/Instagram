## アフレコの録り方

1. **声を先に録って、映像をそれに合わせる。** 映像に後から乗せると、尺に合わせて早口になるか間延びする。
2. **冒頭の一文だけは独立して3〜4テイク録る。** 「これ、解凍してません」を一番言い切れているテイクで使う。
3. **4.0〜5.0秒は何も言わない。** 削る音だけにする。音が変わると人は止まる。
4. **BGMは声より12〜15dB下げる。** 前回は声とBGMが1本にまとまっていたので、次回は分けて調整できるようにしておく。
5. **マイクは口から15〜20cm。** キッチンは反響しやすいので、録音だけ別の部屋でも構わない。

語尾は前回のままでよい。「〜です」「〜ます」で言い切るテンポはレシピの説明と相性が良い。変えるのは冒頭の一文の長さと、その後の間だけ。

## 前回からの変更点

1. 完成形を4.7秒 → **0秒**に
2. テロップを画面幅の1/2以上、白文字＋黒フチに（安全マージン内）
3. 尺 21秒 → **16秒**
4. ラスト3秒のプロフィール誘導カットを**削除**
5. 最後を冒頭とつなげて**ループ**させる
6. CTAをフォロー＋保存の2つ → **保存だけ**に
7. 冒頭のアフレコを、4.1秒の一続き → **1.6秒で言い切って一度黙る**形に

## キャプション

```
凍ったまま削る「ねぎ塩鶏」。解凍時間はゼロです。

冷凍した鶏むね肉は、凍ったままピーラーを当てると
ふわふわのスライスになります。包丁もまな板も使いません。

【材料（2人分）】
・冷凍鶏むね肉 1枚（約300g）
・酒 大さじ1
・長ねぎ 1/2本（みじん切り）
・ごま油 大さじ1
・塩 小さじ1/3
・レモン汁 小さじ1

【作り方】
1. 冷凍鶏むね肉を、凍ったままピーラーで削る
2. 耐熱容器に入れて酒をふり、ラップをして600Wで2分
3. 残りの材料を加えて混ぜる

冷蔵で2日もちます。翌日はごはんにのせても。

作るときに分量を見返せるように、保存しておくとラクです📌

ねぎ塩派？ ごまだれ派？ コメントで教えてください🙌
```

1行目を「レシピはここをタップ👇」から変更。一覧で最初に見えるのはこの1行なので、何が作れるのかを先に置く。最後の問いかけは、コメント0件を動かすため。
